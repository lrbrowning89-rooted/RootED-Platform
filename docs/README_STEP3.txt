# Step 3 — Dashboard

This adds the Flask teacher dashboard.

## Files
- dashboard_v5.py — UI for single-student + class view, frustration trigger, cross-band promotion, CSV export.

## Run
1) In Command Prompt, go to your project folder (the one with ngss.db):
   cd "C:\Users\lbrowning\OneDrive - Wichita Public Schools\Desktop\NGSS_Project"

2) Install Flask (if needed):
   python -m pip install flask

3) Start the dashboard:
   python dashboard_v5.py

4) Open your browser to:
   http://127.0.0.1:5000
