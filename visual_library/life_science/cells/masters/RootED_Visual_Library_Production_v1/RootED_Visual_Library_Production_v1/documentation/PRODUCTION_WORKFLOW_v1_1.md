# RootED Visual Library Production Workflow v1.1

1. Approve the instructional visual reference.
2. Preserve the approved source and record its checksum.
3. Create platform reference exports without modifying the visual design.
4. Build a transparent SVG interaction overlay.
5. Assign stable IDs and accessibility metadata.
6. Validate overlay structure, ID uniqueness, and reference alignment.
7. Integrate the raster and overlay as one responsive visual component.
8. Perform instructional, accessibility, and frontend QA.
9. Lock the released reference and overlay versions.
10. Generate instructional derivatives from the approved reference and interaction package.

Canonical editable masters remain the long-term goal but are deferred from the MVP critical path.
